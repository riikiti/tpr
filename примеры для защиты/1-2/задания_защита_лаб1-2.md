# ЛАБ 1 — МАТРИЧНЫЕ ИГРЫ

## Ключевые формулы

**Чистые стратегии (седловая точка):**
- Для каждой строки i найти `α_i = min_j w_ij` → `W⁻ = max_i α_i` (максиминная стратегия u*)
- Для каждого столбца j найти `β_j = max_i w_ij` → `W⁺ = min_j β_j` (минимаксная стратегия v*)
- Если `W⁻ = W⁺ = W⁰` → игра имеет решение в чистых стратегиях

**Смешанные стратегии для игры 2×2** `W = [[a, b], [c, d]]`:
```
p* = (d − c) / (a − b − c + d)    — вероятность стратегии u1
q* = (d − b) / (a − b − c + d)    — вероятность стратегии v1
W⁰ = (a·d − b·c) / (a − b − c + d)
```
*(предварительно убедиться, что W⁻ ≠ W⁺)*

---

## Общий метод для матриц больше 2×2 (смешанные стратегии)

Применяется когда W⁻ ≠ W⁺ и матрица не 2×2.

### Шаг 1. Устранение доминируемых стратегий

**Доминирование строк (стратегии игрока 1):**
Строка i *доминирует* строку k, если `w_ij ≥ w_kj` для **всех** j (и хотя бы одно строго).
→ Строку k можно **удалить** (игрок 1 никогда её не выберет).

**Доминирование столбцов (стратегии игрока 2):**
Столбец j *доминирует* столбец l, если `w_ij ≤ w_il` для **всех** i (и хотя бы одно строго).
→ Столбец l можно **удалить** (игрок 2 — минимизатор — никогда его не выберет).

> Повторять пока возможно. Цель — свести к матрице 2×2.

**Пример (3×3 → 2×2):**
```
      v1   v2   v3
u1 [  3    6   12  ]
u2 [  0    9   15  ]   ← строка u1 доминирует u3 (3>-3, 6>0, 12>-6)
u3 [ -3    0   -6  ]
```
Сравниваем строки u1 и u3: `3>−3, 6>0, 12>−6` → u1 ≥ u3 по всем столбцам → **удаляем u3**.
После удаления u3 сравниваем столбцы: v1 и v2 — возможно новое доминирование.
Продолжать до 2×2 или невозможности дальнейшего сокращения.

### Шаг 2б. Если осталась матрица k×k (k > 2) — система уравнений

Для **вполне смешанной** игры (все стратегии используются с p > 0) оптимальные стратегии находятся из условия безразличия:

**Нахождение смешанной стратегии игрока 1** `p = (p1, p2, ..., pk)`:

Игрок 2 безразличен между всеми своими стратегиями →
каждая стратегия v_j приносит одинаковый ожидаемый выигрыш игроку 2 (т.е. одинаковый проигрыш игроку 1):

```
w11·p1 + w21·p2 + ... + wk1·pk = W⁰   (для v1)
w12·p1 + w22·p2 + ... + wk2·pk = W⁰   (для v2)
...
w1k·p1 + w2k·p2 + ... + wkk·pk = W⁰   (для vk)
p1 + p2 + ... + pk = 1
```

Это система k+1 уравнений относительно p1,...,pk и W⁰ (k+1 неизвестных). Решается методом подстановки или Гаусса.

**Нахождение смешанной стратегии игрока 2** `q = (q1, q2, ..., qk)`:

Игрок 1 безразличен между своими стратегиями →

```
w11·q1 + w12·q2 + ... + w1k·qk = W⁰   (для u1)
w21·q1 + w22·q2 + ... + w2k·qk = W⁰   (для u2)
...
wk1·q1 + wk2·q2 + ... + wkk·qk = W⁰   (для uk)
q1 + q2 + ... + qk = 1
```

### Шаг 2в. Метод через двойственную задачу ЛП (Задача 2 из Лаб 1)

Если матрица содержит отрицательные элементы — сначала добавить константу C, чтобы все `a_ij = w_ij + C > 0`. Цена игры: `W⁰ = A⁰ − C`.

**Задача для игрока 1** (переменные `x_i = p_i / A⁰`):
```
Σ x_i → min
Σ_i a_ij · x_i ≥ 1,  для всех j
x_i ≥ 0
```

**Двойственная задача для игрока 2** (переменные `y_j = q_j / A⁰`):
```
Σ y_j → max
Σ_j a_ij · y_j ≤ 1,  для всех i
y_j ≥ 0
```

**Восстановление решения:**
```
A⁰ = 1 / Σ x_i = 1 / Σ y_j     — цена игры для матрицы A
p_i = A⁰ · x_i                  — оптимальная смешанная стратегия игрока 1
q_j = A⁰ · y_j                  — оптимальная смешанная стратегия игрока 2
W⁰ = A⁰ − C                     — цена исходной игры
```

### Пример решения системой уравнений (3×3 → 2×3 → 2×2)

```
      v1   v2   v3
u1 [ -3   -3   -6  ]
u2 [  0    9   15  ]
u3 [ -3    0   -6  ]
```

**Шаг 1.** Проверить W⁻ и W⁺:
min строк: −6, 0, −6 → W⁻ = 0 (u2)
max столбцов: 0, 9, 15 → W⁺ = 0 (v1)
**W⁻ = W⁺ = 0** → игра имеет решение в чистых стратегиях!

*(Пример ниже для матрицы без седловой точки.)*

```
      v1   v2   v3
u1 [  1    4    2  ]
u2 [  3    2    4  ]
```
min строк: 1, 2 → W⁻ = 2; max столбцов: 3, 4, 4 → W⁺ = 3. Нет седловой точки.

Доминирование столбцов: v3 vs v1: строка u1: 2>1, строка u2: 4>3 → **v3 доминирует v1** → удаляем v1.

```
      v2   v3
u1 [  4    2  ]
u2 [  2    4  ]
```

Теперь 2×2. Формула: a=4, b=2, c=2, d=4, D = 4−2−2+4 = 4
`p* = (4−2)/4 = 1/2`, `q* = (4−2)/4 = 1/2`, `W⁰ = (16−4)/4 = 3`

**Ответ:** u* = (1/2; 1/2), v* = (0; 1/2; 1/2), **W⁰ = 3**
*(v1 удалена, её вероятность = 0)*

# ЛАБ 2 — БИМАТРИЧНЫЕ ИГРЫ

## Ключевые формулы

**Обозначения:** биматрица задана парами (α_ij, β_ij), где α = W1, β = W2.

**1. Равновесие Нэша в чистых стратегиях:**
- В каждом **столбце** W1 подчеркнуть максимум → лучшие ответы игрока 1
- В каждой **строке** W2 подчеркнуть максимум → лучшие ответы игрока 2
- РН = ситуации, где **оба** значения подчёркнуты

**2. Парето-оптимальные ситуации:**
Ситуация (i,j) — Парето-оптимальна, если не существует (k,l) такой, что α_kl ≥ α_ij и β_kl ≥ β_ij (хотя бы одно строго)

**3. Равновесие по Штакельбергу:**
- Z¹ = множество лучших ответов игрока 1 (лучший ответ на каждую стратегию v_j)
- Z² = множество лучших ответов игрока 2 (лучший ответ на каждую стратегию u_i)
- **1-РШ** (лидер = игрок 1): max W1 на Z²
- **2-РШ** (лидер = игрок 2): max W2 на Z¹

**4. Борьба за лидерство:** каждому игроку выгоднее быть лидером, чем ведомым.
*Достаточное условие:* оба РН Парето-оптимальны и отличаются векторами выигрышей.

**5. Смешанное РН в игре 2×2:**
```
p = (β22 − β21) / (β11 − β12 − β21 + β22)    — вероятность u1
q = (α22 − α12) / (α11 − α12 − α21 + α22)    — вероятность v1
W1⁰ = (α11·α22 − α12·α21) / (α11 − α12 − α21 + α22)
W2⁰ = (β11·β22 − β12·β21) / (β11 − β12 − β21 + β22)
```
*(применимо только если нет доминирующих стратегий)*

---

## Часть В. Биматричные игры 2×2 (полный анализ)

---

### Задание В-1 (есть борьба за лидерство)

Задана биматричная игра 2×2. Найти: РН в чистых и смешанных стратегиях, Парето-оптимальные ситуации, равновесия Штакельберга, борьбу за лидерство.

```
W = | (3, 5)   (0, 1) |
    | (1, 0)   (5, 3) |
```

**Решение на бумаге:**

**Шаг 1. РН в чистых стратегиях.**
Подчёркиваем max в столбцах W1 и max в строках W2:

```
W1:  3↑  0      W2:  5←  1
     1   5↑          0   3←
```

Оба подчёркнуты в (u1,v1): W1=3 — max столбца 1? max(3,1)=3 ✓; W2=5 — max строки 1? max(5,1)=5 ✓ → **РН**
(u2,v2): W1=5 ✓; W2=3 ✓ → **РН**

**РН = {(u1,v1), (u2,v2)}** с выигрышами **(3,5)** и **(5,3)**

**Шаг 2. Парето-оптимальность.**
Все 4 вектора выигрышей: (3,5), (0,1), (1,0), (5,3)
(0,1) доминирован (3,5): 3>0 и 5>1 → не Парето
(1,0) доминирован (3,5): 3>1 и 5>0 → не Парето
(3,5) vs (5,3): несравнимы → оба Парето

**Парето = {(u1,v1), (u2,v2)}**

**Шаг 3. Равновесия Штакельберга.**
Z¹ = {(u1,v1), (u2,v2)}, Z² = {(u1,v1), (u2,v2)}

1-РШ (лидер — игрок 1): max W1 на Z² = max(3, 5) = **5** → **(u2,v2)**, W̄1 = 5
2-РШ (лидер — игрок 2): max W2 на Z¹ = max(5, 3) = **5** → **(u1,v1)**, W̄2 = 5

**Шаг 4. Борьба за лидерство.**
Игрок 1: лидер → 5 (в 1-РШ); ведомый → 3 (в 2-РШ=(u1,v1)). **5 > 3** — выгоднее быть лидером ✓
Игрок 2: лидер → 5 (в 2-РШ); ведомый → 3 (в 1-РШ=(u2,v2)). **5 > 3** — выгоднее быть лидером ✓
**Борьба за лидерство ЕСТЬ.**

**Шаг 5. Смешанное РН.**
α: 3, 0, 1, 5 → D_α = 3−0−1+5 = **7**
β: 5, 1, 0, 3 → D_β = 5−1−0+3 = **7**

`p = (3−0)/7 = 3/7`
`q = (5−0)/7 = 5/7`
`W1⁰ = (3·5 − 0·1)/7 = 15/7 ≈ 2,14`
`W2⁰ = (5·3 − 1·0)/7 = 15/7 ≈ 2,14`

**Смешанное РН:** u⁰ = (3/7; 4/7), v⁰ = (5/7; 2/7), выигрыши **(15/7; 15/7)**

### Задание Г-1 (из примера на защите)

Найти множество ситуаций, равновесных по Нэшу в чистых стратегиях, и множество ситуаций, оптимальных по Парето.

```
         v1      v2      v3
W =  u1 (4, 0)  (1, 5)  (0, 6)
     u2 (2, 3)  (7, 8)  (5, 2)
     u3 (6, 7)  (0, 6)  (1, 1)
```

**Решение на бумаге:**

**Шаг 1. Находим Z¹ (max в каждом столбце W1):**

| | v1 | v2 | v3 |
|---|---|---|---|
| u1 | 4 | 1 | 0 |
| u2 | 2 | **7**↑ | **5**↑ |
| u3 | **6**↑ | 0 | 1 |

col1: max(4,2,6)=6 → u3 → (u3,v1)
col2: max(1,7,0)=7 → u2 → (u2,v2)
col3: max(0,5,1)=5 → u2 → (u2,v3)
Z¹ = {(u3,v1), (u2,v2), (u2,v3)}

**Шаг 2. Находим Z² (max в каждой строке W2):**

| | v1 | v2 | v3 |
|---|---|---|---|
| u1 | 0 | 5 | **6**→ |
| u2 | 3 | **8**→ | 2 |
| u3 | **7**→ | 6 | 1 |

row1: max(0,5,6)=6 → v3 → (u1,v3)
row2: max(3,8,2)=8 → v2 → (u2,v2)
row3: max(7,6,1)=7 → v1 → (u3,v1)
Z² = {(u1,v3), (u2,v2), (u3,v1)}

**Шаг 3. РН = Z¹ ∩ Z²:**

Z¹ = {(u3,v1), **(u2,v2)**, (u2,v3)}
Z² = {(u1,v3), **(u2,v2)**, **(u3,v1)**}
**РН = {(u3,v1), (u2,v2)}** с выигрышами **(6,7)** и **(7,8)**

**Шаг 4. Парето-оптимальные ситуации.**

Все 9 ситуаций:

| Ситуация | W1 | W2 |
|---|---|---|
| (u1,v1) | 4 | 0 |
| (u1,v2) | 1 | 5 |
| (u1,v3) | 0 | 6 |
| (u2,v1) | 2 | 3 |
| **(u2,v2)** | **7** | **8** |
| (u2,v3) | 5 | 2 |
| (u3,v1) | 6 | 7 |
| (u3,v2) | 0 | 6 |
| (u3,v3) | 1 | 1 |

Проверяем (u2,v2)=(7,8): является ли она наибольшей? W1=7 — max в матрице W1, W2=8 — max в матрице W2.
Проверяем (u3,v1)=(6,7): доминируется (u2,v2)=(7,8)? 7>6 И 8>7 → **да, доминируется!**
Все остальные ситуации имеют W1<7 или W2<8 — все доминируются (u2,v2).

**Парето = {(u2,v2)}** — единственная Парето-оптимальная ситуация.

## Типичные вопросы на защите

1. **Что такое седловая точка?** — Ситуация (u*,v*), где W⁻=W⁺. Ни один игрок не выигрывает от отклонения.
2. **Зачем смешанные стратегии?** — Теорема фон Неймана: каждая матричная игра имеет решение в смешанных стратегиях.
3. **Что такое равновесие Нэша?** — Ситуация, от которой ни одному игроку не выгодно отклоняться в одностороннем порядке.
4. **В чём разница между РН и Парето?** — РН устойчиво (нет стимула менять стратегию), Парето эффективно (нельзя улучшить всем). Они могут не совпадать.
5. **Что такое борьба за лидерство?** — Каждому игроку выгоднее быть лидером Штакельберга, чем ведомым.
6. **Как найти смешанное РН в игре 2×2?** — Из условия безразличия: ожидаемый выигрыш от обеих стратегий одинаков.
