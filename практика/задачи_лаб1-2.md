## Тип Е — Формализация ситуации в матричную игру

*(Задача 3 из Лаб 1 и аналоги)*

### Метод решения

```
1. Определить игроков и их роли (максимизатор / минимизатор).

2. Выписать множество стратегий каждого игрока:
   - Игрок 2 (прячет): стратегии = {ячейка 1, ячейка 2, ..., ячейка n}
   - Игрок 1 (ищет): стратегии = все возможные множества проверяемых ячеек

3. Построить платёжную матрицу W:
   W[u_i][v_j] = p_j,  если ячейка j входит в набор проверки u_i
   W[u_i][v_j] = 0,    если ячейка j НЕ входит в набор проверки u_i

4. Решить полученную матричную игру:
   - Найти W⁻ и W⁺
   - Если W⁻ = W⁺  → решение в чистых стратегиях
   - Если W⁻ ≠ W⁺  → искать смешанное решение (редукция, формулы 2×2 или ЛП)
```

---

### Задание Е-1 ✦ РАЗОБРАННЫЙ ПРИМЕР

Имеется **4 ячейки, расположенных по кругу** (1→2→3→4→1).
Игрок 2 прячет предмет в одну из ячеек. Игрок 1 проверяет **2 соседних ячейки** (начиная с выбранной и следующую по кругу).
Вероятность обнаружения предмета в ячейке i равна p_i = i/5.

Формализовать игру, построить платёжную матрицу. Найти решение.

**Решение:**

---

#### Шаг 1. Игроки

- **Игрок 1** (ищет) — **максимизатор**: хочет максимизировать вероятность обнаружения
- **Игрок 2** (прячет) — **минимизатор**: хочет минимизировать эту вероятность

#### Шаг 2. Стратегии

Вероятности обнаружения: p₁=0,2; p₂=0,4; p₃=0,6; p₄=0,8

**Игрок 2** (4 стратегии): v_j = спрятать в ячейку j (j=1,2,3,4)

**Игрок 1** проверяет 2 соседних ячейки по кругу, начиная с выбранной:
```
u1 = проверить {1, 2}
u2 = проверить {2, 3}
u3 = проверить {3, 4}
u4 = проверить {4, 1}
```

#### Шаг 3. Платёжная матрица

`W[u_i][v_j] = p_j` если ячейка j входит в набор u_i, иначе 0.

```
         v1    v2    v3    v4
u1    [ 0,2   0,4    0     0  ]   ← u1 покрывает ячейки 1 и 2
u2    [  0    0,4   0,6    0  ]   ← u2 покрывает ячейки 2 и 3
u3    [  0     0    0,6   0,8 ]   ← u3 покрывает ячейки 3 и 4
u4    [ 0,2    0     0    0,8 ]   ← u4 покрывает ячейки 4 и 1
```

#### Шаг 4. Проверка седловой точки

Умножим матрицу на 5 для удобства (W' = 5·W), решение не изменится:

```
         v1  v2  v3  v4  | min
u1    [   1   2   0   0  |  0  ]
u2    [   0   2   3   0  |  0  ]
u3    [   0   0   3   4  |  0  ]
u4    [   1   0   0   4  |  0  ]
─────────────────────────────────
max       1   2   3   4
```

`W⁻ = max(0,0,0,0) = 0`,  `W⁺ = min(1,2,3,4) = 1`
`W⁻ ≠ W⁺` → седловой точки нет, ищем смешанное решение.

#### Шаг 5. Проверка доминирования

Строки (игрок 1, ищем бо́льшую):
- u1 vs u2: 1>0✓ но 0<3✗ → нет
- u3 vs u4: 0<1✗ → нет
*(аналогично все остальные пары — доминирования нет)*

Столбцы (игрок 2, ищем меньшую):
- v1=[1,0,0,1] vs v3=[0,3,3,0]: 1>0✗ → нет
*(аналогично — доминирования нет)*

Редукция невозможна, матрица 4×4.

#### Шаг 6. Поиск оптимальной подыгры (2×2)

Ищем пару строк и пару столбцов, дающую действительное решение.
Попробуем подыгру **{u1, u3} × {v1, v3}**:

```
         v1  v3
u1    [   1   0  ]
u3    [   0   3  ]
```

`W⁻ = max(0,0) = 0`,  `W⁺ = min(1,3) = 1` → нет седловой → решаем по формулам:

```
a=1, b=0, c=0, d=3
D = 1 − 0 − 0 + 3 = 4

p₁* = (d−c)/D = (3−0)/4 = 3/4   (вероятность u1 в подыгре)
p₃* = 1 − 3/4 = 1/4              (вероятность u3 в подыгре)

q₁* = (d−b)/D = (3−0)/4 = 3/4   (вероятность v1 в подыгре)
q₃* = 1 − 3/4 = 1/4              (вероятность v3 в подыгре)

V' = (1·3 − 0·0)/4 = 3/4         (цена в матрице ×5)
W⁰ = 3/4 ÷ 5 = 3/20 = 0,15
```

#### Шаг 7. Проверка допустимости в исходной игре

Стратегия игрока 1: **p* = (3/4, 0, 1/4, 0)** [u2 и u4 не используются]
Проверим ожидаемый выигрыш против КАЖДОЙ стратегии игрока 2 (в матрице ×5):

```
E[v1] = 1·(3/4) + 0·(0) + 0·(1/4) + 1·(0) = 3/4 = V' ✓
E[v2] = 2·(3/4) + 2·(0) + 0·(1/4) + 0·(0) = 3/2 > V' ✓  (игрок 2 не выберет v2)
E[v3] = 0·(3/4) + 0·(0) + 3·(1/4) + 0·(0) = 3/4 = V' ✓
E[v4] = 0·(3/4) + 0·(0) + 4·(1/4) + 4·(0) = 1   > V' ✓  (игрок 2 не выберет v4)
```

Игрок 2 не может улучшить результат → p* допустима ✓

Стратегия игрока 2: **q* = (3/4, 0, 1/4, 0)** [v2 и v4 не используются]
Проверим ожидаемый выигрыш против КАЖДОЙ стратегии игрока 1:

```
E[u1] = 1·(3/4) + 2·(0) + 0·(1/4) + 0·(0) = 3/4 = V' ✓
E[u2] = 0·(3/4) + 2·(0) + 3·(1/4) + 0·(0) = 3/4 = V' ✓
E[u3] = 0·(3/4) + 0·(0) + 3·(1/4) + 4·(0) = 3/4 = V' ✓
E[u4] = 1·(3/4) + 0·(0) + 0·(1/4) + 4·(0) = 3/4 = V' ✓
```

Все стратегии игрока 1 дают одинаковый результат → q* допустима ✓

#### Ответ

```
p* = (3/4;  0;  1/4;  0)   — игрок 1 проверяет {1,2} с вер. 3/4, {3,4} с вер. 1/4
q* = (3/4;  0;  1/4;  0)   — игрок 2 прячет в ячейку 1 с вер. 3/4, в ячейку 3 с вер. 1/4
W⁰ = 3/20 = 0,15
```

## Тип Ж — Смешанные стратегии через пару двойственных задач ЛП

*(Задача 2 из Лаб 1)*

### Метод решения

```
1. Проверить W⁻ ≠ W⁺ (нет решения в чистых стратегиях).

2. Исключить доминируемые стратегии (если есть).

3. Если в матрице есть неположительные элементы — добавить константу C:
   a_ij = w_ij + C,   где C > |min w_ij|
   Тогда W⁰ = A⁰ − C.

4. Записать пару двойственных задач ЛП.
   Пусть матрица A имеет размер m×n (m строк, n столбцов).

   Задача игрока 1 (переменные x_i = p_i / A⁰):
       Σ x_i → min
       Σ_i a_ij · x_i ≥ 1,  для каждого j = 1..n
       x_i ≥ 0

   Задача игрока 2 (переменные y_j = q_j / A⁰):
       Σ y_j → max
       Σ_j a_ij · y_j ≤ 1,  для каждого i = 1..m
       y_j ≥ 0

5. Решить ЛП для МЕНЬШЕЙ задачи (меньше переменных = проще):
   - Если m = 2: решать задачу игрока 1 (2 переменные → графически или подстановкой)
   - Если n = 2: решать задачу игрока 2 (2 переменные → графически)

   Для задачи с 2 переменными найти все точки пересечения активных ограничений,
   выбрать допустимую точку с наименьшим (для min) или наибольшим (для max) значением функции.

6. Найти A⁰ = 1 / Σ x_i  (или = 1 / Σ y_j — должно совпадать).

7. Найти решение второй задачи из условия дополняющей нежёсткости:
   - Если x_i > 0 → i-е ограничение задачи игрока 2 АКТИВНО (обращается в равенство).
   - Если y_j > 0 → j-е ограничение задачи игрока 1 АКТИВНО.
   - Если ограничение не активно → соответствующая переменная = 0.

8. Восстановить стратегии:
   p_i = A⁰ · x_i,   q_j = A⁰ · y_j

9. W⁰ = A⁰ − C.
```

---

### Задание Ж-1 (2×3, все элементы положительны)

```
        v1  v2  v3
W =  u1 [ 1   4   3 ]
     u2 [ 5   1   2 ]
```

Убедиться, что W⁻ ≠ W⁺ и доминируемые стратегии отсутствуют.
Свести к паре двойственных задач ЛП. Найти оптимальные смешанные стратегии и цену игры.

**Решение:**

**Шаг 1. Проверка наличия седловой точки**

Минимумы по строкам:
- u1: min(1, 4, 3) = **1**
- u2: min(5, 1, 2) = **1**

W⁻ = max(1, 1) = **1**

Максимумы по столбцам:
- v1: max(1, 5) = **5**
- v2: max(4, 1) = **4**
- v3: max(3, 2) = **3**

W⁺ = min(5, 4, 3) = **3**

W⁻ = 1 ≠ 3 = W⁺ → **седловой точки нет**, игра не имеет решения в чистых стратегиях.

**Шаг 2. Проверка доминирования**

Игрок 1 (строки, максимизатор — ищем строку ≥ другой строки):
- u1 = (1, 4, 3),  u2 = (5, 1, 2):  u1 < u2 по v1, но u1 > u2 по v2 → **ни одна строка не доминирует**.

Игрок 2 (столбцы, минимизатор — ищем столбец ≤ другому столбцу):
- v1=(1,5), v2=(4,1): v1 < v2 по u1, v1 > v2 по u2 → нет доминирования.
- v3=(3,2) vs v1=(1,5): v3 > v1 по u1, v3 < v1 по u2 → нет доминирования.
- v3=(3,2) vs v2=(4,1): v3 < v2 по u1, v3 > v2 по u2 → нет доминирования.

**Доминируемых стратегий нет.**

**Шаг 3. Добавление константы**

Все элементы матрицы положительны → константа **C = 0**, матрица A = W.

**Шаг 4. Составление пары двойственных задач ЛП**

Обозначим: x_i = p_i / A⁰  (i=1,2),  y_j = q_j / A⁰  (j=1,2,3), где A⁰ = W⁰ + C = W⁰.

**Задача игрока 1** (минимизация, 2 переменных → решаем графически):
```
min  z = x₁ + x₂
при  1·x₁ + 5·x₂ ≥ 1   (по v1)
     4·x₁ + 1·x₂ ≥ 1   (по v2)
     3·x₁ + 2·x₂ ≥ 1   (по v3)
     x₁, x₂ ≥ 0
```

**Двойственная задача игрока 2** (максимизация):
```
max  w = y₁ + y₂ + y₃
при  1·y₁ + 4·y₂ + 3·y₃ ≤ 1   (по u1)
     5·y₁ + 1·y₂ + 2·y₃ ≤ 1   (по u2)
     y₁, y₂, y₃ ≥ 0
```

**Шаг 5. Графическое решение задачи игрока 1**

Ищем пересечения граничных прямых и проверяем выполнение всех ограничений.

**Пересечение (1) и (2):** x₁ + 5x₂ = 1,  4x₁ + x₂ = 1
- x₂ = 3/19,  x₁ = 4/19,  z = 7/19 ≈ 0.368
- Проверка (3): 3·(4/19) + 2·(3/19) = 18/19 < 1 → **не выполнено** ✗ (точка недопустима)

**Пересечение (1) и (3):** x₁ + 5x₂ = 1,  3x₁ + 2x₂ = 1
- Из (1): x₁ = 1 − 5x₂; подставляем в (3): 3(1 − 5x₂) + 2x₂ = 1 → −13x₂ = −2 → x₂ = **2/13**
- x₁ = 1 − 10/13 = **3/13**,  z = 3/13 + 2/13 = **5/13** ≈ 0.385
- Проверка (2): 4·(3/13) + 2/13 = 14/13 > 1 ✓ **(точка допустима)**

**Пересечение (2) и (3):** 4x₁ + x₂ = 1,  3x₁ + 2x₂ = 1
- x₁ = 1/5,  x₂ = 1/5,  z = 2/5 = 0.4
- Проверка (1): 1/5 + 5·(1/5) = 6/5 > 1 ✓ (точка допустима)

Из допустимых точек выбираем ту, где z **минимально**:
- (1)∩(3): z = 5/13 ≈ 0.385
- (2)∩(3): z = 2/5 = 0.400

**Минимум достигается в точке (1)∩(3):** x₁ = 3/13, x₂ = 2/13.

**Шаг 6. Восстановление стратегии игрока 1**

A⁰ = 1/z = **13/5**

p₁ = A⁰ · x₁ = (13/5) · (3/13) = **3/5**
p₂ = A⁰ · x₂ = (13/5) · (2/13) = **2/5**

→ **p* = (3/5; 2/5)**

**Шаг 7. Нахождение стратегии игрока 2 (принцип дополняющей нежёсткости)**

Так как x₁ > 0 и x₂ > 0, оба ограничения двойственной задачи **активны** (равенства):
```
y₁ + 4y₂ + 3y₃ = 1
5y₁ + y₂ + 2y₃ = 1
```

Ограничение (2) в задаче игрока 1 **не активно** (14/13 > 1) → по принципу дополняющей нежёсткости **y₂ = 0**.

Система с y₂ = 0:
```
y₁ + 3y₃ = 1
5y₁ + 2y₃ = 1
```
Из первого: y₁ = 1 − 3y₃; подставляем: 5(1 − 3y₃) + 2y₃ = 1 → −13y₃ = −4 → y₃ = **4/13**

y₁ = 1 − 12/13 = **1/13**

q₁ = A⁰ · y₁ = (13/5) · (1/13) = **1/5**
q₂ = 0
q₃ = A⁰ · y₃ = (13/5) · (4/13) = **4/5**

→ **q* = (1/5; 0; 4/5)**

**Шаг 8. Цена игры**

W⁰ = A⁰ − C = 13/5 − 0 = **13/5 = 2.6**

**Шаг 9. Проверка**

Ожидаемый выигрыш при q*:
- E(u1, q*) = 1·(1/5) + 4·0 + 3·(4/5) = 1/5 + 12/5 = **13/5** = W⁰ ✓
- E(u2, q*) = 5·(1/5) + 1·0 + 2·(4/5) = 5/5 + 8/5 = **13/5** = W⁰ ✓

Ожидаемый выигрыш при p*:
- E(p*, v1) = 1·(3/5) + 5·(2/5) = 3/5 + 10/5 = **13/5** = W⁰ ✓
- E(p*, v2) = 4·(3/5) + 1·(2/5) = 12/5 + 2/5 = **14/5 > W⁰** ✓ (v2 невыгодна игроку 2)
- E(p*, v3) = 3·(3/5) + 2·(2/5) = 9/5 + 4/5 = **13/5** = W⁰ ✓

Все условия оптимальности выполнены.

**Ответ:** p* = (3/5; 2/5),  q* = (1/5; 0; 4/5),  **W⁰ = 13/5 = 2.6**
