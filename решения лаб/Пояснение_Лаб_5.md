# Лабораторная работа №5. Динамическое программирование (задача распределения ресурсов)

## Вариант 4

---

## 1. Теоретические основы

### 1.1. Принцип оптимальности Беллмана

Принцип оптимальности Беллмана формулируется следующим образом:

> **Каково бы ни было состояние системы в результате какого-либо числа шагов, на ближайшем шаге нужно выбирать управление так, чтобы оно в совокупности с оптимальным управлением на всех последующих шагах приводило к оптимальному выигрышу на всех оставшихся шагах, включая данный.**

Иными словами, оптимальная стратегия обладает тем свойством, что, каковы бы ни были начальное состояние и начальное решение, последующие решения должны составлять оптимальную стратегию относительно состояния, полученного в результате первого решения.

### 1.2. Метод динамического программирования

Метод динамического программирования позволяет свести задачу оптимизации с $n$ переменными к последовательности $n$ задач с одной переменной. Решение строится в два этапа:

1. **Обратный ход (условная оптимизация)** — двигаясь от последнего предприятия к первому, для каждого возможного остатка ресурса находим оптимальное распределение среди оставшихся предприятий.
2. **Прямой ход (безусловная оптимизация)** — двигаясь от первого предприятия к последнему, последовательно определяем оптимальные значения переменных.

---

## 2. Постановка задачи

Имеется $B = 6$ единиц ресурса, которые необходимо распределить между $n = 3$ предприятиями. Эффективность $j$-го предприятия при вложении $x_j$ единиц ресурса задаётся функцией $f_j(x_j)$.

### 2.1. Исходные данные

| $x_j$ | $f_1(x_j)$ | $f_2(x_j)$ | $f_3(x_j)$ |
|:------:|:-----------:|:-----------:|:-----------:|
| 0      | $-2$        | $1$         | $3$         |
| 1      | $18$        | $6$         | $10$        |
| 2      | $26$        | $24$        | $22$        |
| 3      | $29$        | $38$        | $35$        |
| 4      | $43$        | $46$        | $45$        |
| 5      | $54$        | $52$        | $56$        |
| 6      | $73$        | $76$        | $68$        |

### 2.2. Математическая модель

Требуется найти такое распределение $X^* = (x_1^*, x_2^*, x_3^*)$, которое максимизирует суммарную эффективность:

$$f(x_1, x_2, x_3) = f_1(x_1) + f_2(x_2) + f_3(x_3) \to \max$$

при ограничениях:

$$x_1 + x_2 + x_3 = 6$$

$$x_j \in \{0, 1, 2, 3, 4, 5, 6\}, \quad j = 1, 2, 3$$

### 2.3. Рекуррентные соотношения Беллмана

Введём функцию Беллмана $L_k(S)$ — максимальная суммарная эффективность предприятий с номерами $k, k+1, \ldots, n$ при распределении между ними $S$ единиц ресурса.

Рекуррентные соотношения имеют вид:

**Для последнего предприятия** ($k = n = 3$):

$$L_3(S) = \max_{0 \le x_3 \le S} f_3(x_3) = f_3(S)$$

Поскольку третье предприятие единственное оставшееся, ему выделяется весь остаток ресурса: $x_3^*(S) = S$.

**Для промежуточных предприятий** ($k = 2$):

$$L_2(S) = \max_{0 \le x_2 \le S} \left\{ f_2(x_2) + L_3(S - x_2) \right\}$$

**Для первого предприятия** ($k = 1$):

$$L_1(B) = \max_{0 \le x_1 \le B} \left\{ f_1(x_1) + L_2(B - x_1) \right\}$$

Значение $L_1(B)$ и есть максимальная суммарная эффективность.

## 3. Обратный ход (условная оптимизация)

### 3.1. Шаг 1: предприятие $j = 3$

На этом шаге последнему предприятию достаётся весь оставшийся ресурс $S$. Поэтому:

$$L_3(S) = f_3(S), \quad x_3^*(S) = S$$

| $S$ | $L_3(S) = f_3(S)$ | $x_3^*(S)$ |
|:---:|:------------------:|:-----------:|
| 0   | $3$                | $0$         |
| 1   | $10$               | $1$         |
| 2   | $22$               | $2$         |
| 3   | $35$               | $3$         |
| 4   | $45$               | $4$         |
| 5   | $56$               | $5$         |
| 6   | $68$               | $6$         |

---

### 3.2. Шаг 2: предприятие $j = 2$

Для каждого возможного остатка $S$ (от 0 до 6) перебираем все допустимые значения $x_2$ (от 0 до $S$) и вычисляем:

$$z_2(S, x_2) = f_2(x_2) + L_3(S - x_2)$$

#### Таблица условной оптимизации для $j = 2$

| 4   | $1+45=46$   | $6+35=41$   | $24+22=46$  | $38+10=48$  | $46+3=49$   | —           | —           | **49**    | $4$         |

### 3.3. Шаг 3: предприятие $j = 1$

На этом шаге $S = B = 6$ (весь ресурс). Перебираем все $x_1$ от 0 до 6:

$$z_1(6, x_1) = f_1(x_1) + L_2(6 - x_1)$$

| $x_1$ | $f_1(x_1)$ | $L_2(6 - x_1)$ | $z_1(6, x_1)$ |
|:------:|:-----------:|:---------------:|:--------------:|
| $0$    | $-2$        | $L_2(6) = 79$   | $-2 + 79 = 77$ |
| $1$    | $18$        | $L_2(5) = 60$   | $18 + 60 = 78$ |
| $2$    | $26$        | $L_2(4) = 49$   | $26 + 49 = 75$ |
| $3$    | $29$        | $L_2(3) = 41$   | $29 + 41 = 70$ |
| $4$    | $43$        | $L_2(2) = 27$   | $43 + 27 = 70$ |
| $5$    | $54$        | $L_2(1) = 11$   | $54 + 11 = 65$ |
| $6$    | $73$        | $L_2(0) = 4$    | $73 + 4 = 77$  |

Максимум:

$$L_1(6) = \max\{77,\; \mathbf{78},\; 75,\; 70,\; 70,\; 65,\; 77\} = 78$$

Достигается при $x_1^* = 1$.

---

## 4. Прямой ход (безусловная оптимизация)

Последовательно восстанавливаем оптимальное решение, двигаясь от первого предприятия к последнему.

**Шаг 1.** Из шага 3 обратного хода:

$$x_1^* = 1$$

Остаток ресурса: $S_2 = B - x_1^* = 6 - 1 = 5$

**Шаг 2.** Из таблицы $L_2$ при $S = 5$:

$$x_2^* = x_2^*(5) = 3$$

Остаток ресурса: $S_3 = S_2 - x_2^* = 5 - 3 = 2$

**Шаг 3.** Из таблицы $L_3$ при $S = 2$:

$$x_3^* = x_3^*(2) = 2$$

### Оптимальное решение:

$$\boxed{X^* = (x_1^*, x_2^*, x_3^*) = (1,\; 3,\; 2)}$$

### Проверка:

$$x_1^* + x_2^* + x_3^* = 1 + 3 + 2 = 6 = B \quad \checkmark$$

### Максимальная суммарная эффективность:

$$f^* = f_1(1) + f_2(3) + f_3(2) = 18 + 38 + 22 = \boxed{78}$$

---

## 5. Сравнение с равномерным распределением

При равномерном распределении ресурса каждому предприятию выделяется:

$$x_j = \frac{B}{n} = \frac{6}{3} = 2, \quad j = 1, 2, 3$$

Суммарная эффективность при равномерном распределении:

$$f_{\text{равн}} = f_1(2) + f_2(2) + f_3(2) = 26 + 24 + 22 = 72$$

### Потеря эффективности:

$$\Delta f = f^* - f_{\text{равн}} = 78 - 72 = 6$$

$$\delta = \frac{f^* - f_{\text{равн}}}{f^*} \cdot 100\% = \frac{78 - 72}{78} \cdot 100\% \approx 7{,}7\%$$

Таким образом, равномерное распределение ресурса приводит к потере **7,7%** эффективности по сравнению с оптимальным распределением.

---

## 6. Выводы

1. Методом динамического программирования решена задача оптимального распределения $B = 6$ единиц ресурса между $n = 3$ предприятиями.

2. Оптимальное распределение: $X^* = (1, 3, 2)$, то есть первому предприятию следует выделить 1 единицу, второму — 3 единицы, третьему — 2 единицы ресурса.

3. Максимальная суммарная эффективность составляет $f^* = 78$.

4. По сравнению с равномерным распределением $(2, 2, 2)$ оптимальное решение даёт выигрыш в 6 единиц эффективности (7,7%), что подтверждает целесообразность применения метода динамического программирования.

5. Принцип оптимальности Беллмана позволяет свести многомерную задачу оптимизации к последовательности одномерных задач, что существенно сокращает объём вычислений по сравнению с полным перебором.
